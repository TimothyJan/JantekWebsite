Smart Reader JSR-200:
Standalone Access Control System

The JSR-200 is a standalone, single door controller, using ISO ABA Track II Magnetic stripe reader and card. Operation modes are Card only, Keypad only, Card with Keypad or Facility Code only. Card capacity is 9,999 users. Programmable door release time from 1~250 seconds through Control Card.

Features:

  • Standalone, single door control.
  • Using ISO ABA Track II Magnetic stripe reader and card.
  • Operating Mode: Card only, Keypad only, Card with Keypad or Facility Code only.
  • Card capacity is 9,999 users.
  • Programmable door release time: 1~250 seconds.
  • Access code can be added or deleted using control card.
  • Enable/disable alarm loop through Control Card.
  • Built-in Watch Dog, the system never hang.
  • Built-in tamper switch detects when case is forced open.
  • Built-in electric buzzer for audible card entry and programming.
  • Data is protected even after power failure.
  • Machined Zinc housing in high durable.
  • With hidden code function under keypad only open door mode.

Specifications:
