WEB PUNCH

Jantek's Web Punch is completely web-enabled and utilizes state of the art technology. It is a companion product to our 32-bit Jupiter 9.0 Time and Attendance Software.

Web Punch makes it possible for employees to submit time and attendance with the convenience of an intranet or Internet web page. No need to send in Timesheets. Perfect for small or large sized companies.

Software Features

Access system through popular web browsers such as Microsoft Edge, Mozilla FireFox, Google Chrome, or Safari.

Enable employees to view their time card history, total hours worked and accrual benefits.

(Optional) public and private messaging not only enables supervisor to send messages to employees, but also messages from one employee to another.

Utilizes server's time to avoid any misrepresentation of punches.

Handles multiple time zones efficiently.

Designed to be hosted on a Windows Server (Server 2008, Server 2008 R2, Server 2012, Server 2012 R2, Server 2016, Server 2019, or Server 2022).

Designed to operate under Windows 8, Windows 8.1, Windows 10, Windows 11 and Linux network environments.

Reduces supervisor time spent with timekeeping and scheduling.

Eliminate time cards, their preparation, collection and distribution costs.

Web-based electronic Timesheets via company intranet or Internet.
