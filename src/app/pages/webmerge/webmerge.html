WEB MERGE

The Web Merge module for Jupiter 9.0 Time & Attendance software is an excellent solution for companies with multiple locations that edit their timecard data in each branch, then send the data to the corporate headquarters for payroll processing.

Using any standard Web browser, branches can upload their time and attendance data directly to another Jupiter 9.0 database. The data is instantly available in the headquarters database and can be manipulated, is available for reports and can be exported for payroll processing.

Software Features

All popular browsers including Internet Explorer, Microsoft Edge, Mozilla FireFox, Google Chrome or Safari may be used.

Companies with multiple branches can feed employee time data to a central Jupiter 9.0 database.

Policy rules such as overtime and rounding from the central Jupiter database will be automatically applied to the new data.

Designed to operate under Windows (version 8, 8.1, 10 and 11) and Linux network environments.
