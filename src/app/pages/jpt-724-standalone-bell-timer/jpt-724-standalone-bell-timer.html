Standalone
Bell Timer

The JPT-724 is a standalone programmable 7 day / 24 hour, multiple event bell timer. It can perform up to 28 independent schedule events. Each of these events may be programmed to occur at any time, any day of the week. The block feature can be used to repeat the same event Monday through Friday. All schedules programmed are stored in the EEPROM memory and will not be lost due to a power failure.

There are 3 types of events to choose from:

  • ✓

    RELAY ON to turn on the bell

  • ✓

    RELAY OFF to turn off the bell

  • ✓

    PULSE for bell duration from 1 to 15 seconds (duration is programmable by the installer).
