DATA COLLECTION AND TIME CLOCKS

JANTEK ELECTRONICS offers a wide variety of data collection readers and terminals for the Jupiter Time & Attendance software: swipe card terminals that read barcode/magstripe, and proximity badge readers; biometric solutions (hand readers, fingerprint readers, facial recognition), and virtual punch options that require no specialized hardware, terminals or other readers. Cards used for Time & Attendance are also interchangeable between swipe card terminals and access control devices.

Jantek Web applications are designed using a 3-Tier architecture which incorporates Multi-threaded COM+ applications as the middle tier and a SQL Server database as the backend tier. The entire calculation engine and business logic are built into COM+ applications and run on the server itself. This technology gives outstanding performance and stability even on low speed network.

Web Punch

Employees can punch IN and OUT through the Internet or company intranet using a web browser. It integrates directly to the JTA database on the server, eliminating the need to collect data. 

In addition, powerful messaging features alert users when there are unviewed public and/or private messages. Employees can also review total hours worked in the pay period and previous punches.

Web Punch utilizes a 3-tier architecture to give excellent performance on even a low speed network as the entire calculation engine and business logic run solely on the server machine.

Web Punch is also available in a SQL version, compatible with the Jupiter 9.0 CS software.
