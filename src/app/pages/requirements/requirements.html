SYSTEM REQUIREMENTS FOR JUPITER 9.X SOFTWARE

JTA Jupiter Version 9.0 (Standard)

Minimum PC Requirements:

1 GHz (or faster) 32-bit or 64-bit CPU

System RAM:

2 GB - Windows 8 / 8.1 / 10 / 11 (32-bit)

4 GB - Windows 8 / 8.1 / 10 / 11 (64-bit)

8 GB available hard disk space (more needed for larger data files)

Windows 8 / Windows 8.1 / Windows 10 / Windows 11

Available RS-232 Serial port (if using direct-connect clock)

Modem (if using remote timeclock; avoid using Winmodems)

Network card (if using Ethernet timeclock)

SVGA display

CD-ROM, DVD-ROM, or BD-ROM drive

Note: Professional edition of the operating system is recommended because of networking limitations of the Home editions (e.g. cannot connect to domain)

JTA Jupiter Version 9.0 SX

Minimum PC Requirements:

1 GHz (or faster) 32-bit or 64-bit CPU

System RAM:

2 GB - Windows 8 / 8.1 / 10 / 11 (32-bit)

4 GB - Windows 8 / 8.1 / 10 / 11 (64-bit)

300 MB available hard disk space (more needed for larger data files)

Windows 8 / Windows 8.1 / Windows 10 / Windows 11

Available RS-232 Serial port

SVGA display

CD-ROM, DVD-ROM, or BD-ROM drive

JTA Jupiter Version 9.0 CS (SQL)

Minimum PC Server Requirements:

Dual-core 2GHz (or faster) 32-bit or 64-bit CPU

4 GB (32-bit), 8 GB (64-bit)

80 GB available hard disk space (at least 250 GB hard drive recommended)

Windows Server 2008 / Windows Server 2008 r2 / Windows Server 2012 / Windows Server 2012 R2 / Windows Server 2016 / Windows Server 2019 / Windows Server 2012

MS-SQL Server 2005 (or later) with appropriate licensing for sufficient number of concurrent users

Available RS-232 Serial port (if using direct connect timeclock)

Modem (if using remote timeclock; avoid using Winmodems)

100Mb Network card (1Gb recommended)

SVGA display

CD-ROM, DVD-ROM, or BD-ROM drive

System RAM:

4 GB - Windows 8 / 8.1 / 10 / 11 (64-bit)

2 GB available hard disk space ( 120 GB hard drive recommended)

Windows 7 / Windows 8 / Windows 10 / Windows 11

Available RS-232 Serial port (if using direct connect timeclock)
